# Client Retention Analytics

Тестовое задание по аудиту клиентских флайтов и анализу пролонгации и оттока клиентов.

## Задача

Провести аудит исходного отчёта на основе данных о проектах, работах,
изменениях услуг и сроках оказания услуг.

В рамках работы:
- проверены статусы клиентских флайтов;
- выявлены расхождения и неоднозначные случаи;
- сформирован исправленный отчёт;
- рассчитаны показатели пролонгации и оттока;
- подготовлен интерактивный дашборд в Yandex DataLens.

## Дашборд

Интерактивный дашборд:

**[Открыть дашборд в Yandex DataLens](https://us.datalens-front.cloud.yandex.net/jht0cib5ace82)**

Дашборд содержит:
- количество уникальных клиентов и флайтов;
- долю пролонгации и оттока;
- распределение флайтов по статусам;
- исходы флайтов в разрезе типов услуг;
- долю пролонгации по типам услуг;
- динамику запуска новых флайтов;
- список флайтов, требующих дополнительного внимания.

> Доли пролонгации и оттока рассчитываются только по флайтам
> с определённым исходом. Неизвестные статусы и разовые работы
> исключены из расчёта.

## Структура проекта

- `AUDIT.md` — результаты аудита, найденные расхождения и спорные случаи;
- `data/report_fixed.csv` — исправленный итоговый отчёт;
- `data/report_fixed_datalens.csv` — данные, подготовленные для Yandex DataLens;
- `src/audit_check.py` — код проверки и подготовки данных.

## Результаты

По результатам аудита:
- выявлено 11 уникальных клиентов;
- сформировано 18 клиентских флайтов;
- для 16 флайтов определён исход;
- доля пролонгации — 31,25%;
- доля оттока — 68,75%.

Неоднозначные случаи, в которых исходные источники не позволяют
однозначно определить статус флайта, сохранены отдельно и описаны
в `AUDIT.md`.
